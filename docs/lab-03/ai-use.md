## Critical-thinking

I used AI as a support tool, but I still made the final decisions. I compared AI suggestions with the official Lab 3 handout, checked the code and tests, and verified the database, API, and UI myself. I also used GitHub Issues, feature branches, Pull Requests, peer review, and staged integration to make sure each issue was completed correctly. This taught me that AI-generated work still needs human checking, testing, and verification against the official requirements.

## Reflection

During Lab 3, AI helped me break the requirements into smaller GitHub Issues and prepare specifications, test plans, API contracts, UI requirements, implementation tasks, testing, and final evidence preparation. It also helped me understand and follow the required GitHub workflow. However, I learned that I should not rely on AI blindly, so I checked the official Lab 3 handout, reviewed the implementation, ran tests, examined Git and Pull Request history, and used my own judgment. Overall, AI made my work faster and more organized while I remained responsible for the final implementation, testing, evidence, and submission.
